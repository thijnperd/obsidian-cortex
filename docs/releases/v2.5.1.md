# Cortex 2.5.1 — Notes Studio keeps unsaved edits when the open note is reopened

- **Re-opening the open note no longer discards typing:** clicking the note that is already on screen (its card in the list, its tab, a history entry) used to refetch it and reset the draft. If that load finished after you had started typing, the draft was replaced by the copy on disk and the next save wrote the pre-edit text. `openNote()` now skips the refetch while the note on screen has unsaved work, and re-checks after the fetch so a load that lands after the first keystroke cannot overwrite the draft.
- **Live Preview smoke steps tap text, not links:** the desktop and mobile live-preview steps in `tests/smoke.mjs` picked the last paragraph, which in the demo vault ends in wikilinks; the tap followed the link and navigated instead of opening the editor. Both now pick a paragraph that holds only plain text, so tap-to-edit stays covered on desktop and on the `390×844` mobile shell.
- **Restored `web smoke (playwright)`:** the job now passes in both `ci` and `release`, on a branch dispatch and on `main`.
