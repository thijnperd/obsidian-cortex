# Cortex 2.2.1 - Boot fix

- **Fixed the app staying on the \"Opening vault...\" screen.** The 2.2.0 UI rewrite dropped several helpers (boot overlay, toasts, tooltips, palette results), so the page never finished loading. This is why the app seemed to take forever to open; indexing your vaults takes under a second.
- In-app updates (Vault settings > Check for updates, plus the banner on launch) work again, since they run after boot. From now on you can update without downloading the installer by hand.
