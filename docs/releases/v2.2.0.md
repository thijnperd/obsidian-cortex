# Cortex 2.2 - Notes studio

**A dedicated place to write: note list, editor and connections side by side, with a slash menu and Obsidian-style shortcuts.**

- **Notes tab** with filter, scopes (All, Pinned, Recent, folder), sorting and quick capture to the Inbox.
- **Connections pane** with backlinks, unlinked mentions and related notes, each with a snippet.
- **Slash menu** for headings, tasks, tally boxes, callouts, tables, math, code, quotes, dividers, today's date and wikilinks.
- **Shortcuts:** `Ctrl L` toggle task, `Ctrl Shift D` duplicate line, `Alt Up/Down` move line, `?` cheat sheet.

## Install
 `CortexSetup-2.2.0.exe` or the platform archives from the assets below.
