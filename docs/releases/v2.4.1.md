# Cortex 2.4.1 - Mobile iOS shell & Obsidian-style Live Preview

- **Simplified iOS & mobile web UI (`<= 760px`):** fixes the safe-area toolbar squeeze, streamlines the top bar, places the four primary views (`Notes`, `Graph`, `Brain`, `Decisions`) plus a `More` sheet in a fixed bottom iOS dock, switches mobile drawers to `100svh`, and adds a two-step Notes list → editor flow (`← Notes`).
- **Obsidian-style Live Preview editor:** sets **Live** as the default Notes editor mode alongside `Source`, `Read`, and desktop `Split`—featuring collapsible Properties with editable `#tag` pills, inline document title editing, tap-to-edit Markdown blocks, cross-block keyboard navigation, `#tag` autocomplete, a 1-tap `/` command button in the formatting toolbar, and a selection formatting bubble.
- **PWA cache & verification:** updates the service worker cache (`cortex-v2.4.1-1`) and adds Live Preview unit tests plus `390×844` touch/mobile smoke tests.
