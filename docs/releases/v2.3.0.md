# Cortex 2.3.0 - Folder explorer

- **Notes tab shows your folders:** a collapsible tree of the real vault hierarchy with note counts, single-line note rows, and a Folders/List toggle. Filtering opens the matching folders; the open note's folders expand automatically.
- **Calmer layout:** copy link, reveal, locate in graph and zen mode moved into one `...` menu; the flat list hides excerpts until hover.
- Active tab scrolls into view.
