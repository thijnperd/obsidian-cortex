# Cortex 2.5.0 — Quiet Editorial Studio UI overhaul & browser vault engine

- **Calm top bar & clean Windows paths:** consolidated secondary toolbar actions (`Today's note`, `Random note`, `Guided tour / Replay`, `Switch theme`, `Keyboard shortcuts`) into a light-dismiss `⋯` Utilities popover (`#toolbar-more-menu`), simplified the vault switcher to a single line, and stripped Windows `\\?\` / `\\?\UNC\` verbatim prefixes everywhere paths are shown.
- **No double sidebar & collapsed Inspector default:** in desktop Notes mode, hides the duplicate global sidebar so `#sidebar-toggle` (`[`) controls the Notes list pane directly; collapses the right Connections Inspector by default behind a subtle numeric badge; wraps `Vaults` and `Tallies` in native `<details>` disclosures; and hides empty `Pinned` hints and the bottom shortcut strip.
- **Unobstructed bottom notes & lists:** hides the `.canvas-status` (`123 notes · ...`) pill on all non-3D views (`notes`, `atlas`, `bento`, `decisions`) and adds `64px` bottom clearance to `.notes-feed` so the bottom-most note is always clickable.
- **Full browser / GitHub Pages vault support:** lets PC/Mac users open individual `.md` files or entire Obsidian vault folders directly in static mode (`#local-vault` + drag-and-drop), strips picked root/wrapper folders so folders & regions map cleanly into the 3D brain, populates Decisions cards from frontmatter, persists IndexedDB edits, and exports notes via **Download `.md`**.
- **Documented roadmap & regression tests:** tracks the overhaul vision, invariants, and checklist in `docs/ui-overhaul-todo.md`, bumps PWA cache (`cortex-v2.5.0-1`), adds `cleanDisplayPath` unit tests, and verifies desktop, mobile (`390×844`), static PC, and UI-overhaul invariants via Playwright (`tests/smoke.mjs`).
