# Cortex 2.3.1 - Universe layout

- **Folder galaxies now spread over a sphere at every vault size.** Vaults with twelve folders or fewer used to sit on two offset crowns, which read as a barrel with the journal's orbit for a rim; the sphere only appeared above twelve folders. The Graph view now uses the same universe at any folder count.
- The journal folder keeps its own tilted orbit, and nothing else about the layout, labels or other views changed.
