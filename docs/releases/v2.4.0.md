# Cortex 2.4.0 - Source comparison, offline mode & CI smoke gate

- **Deterministic source comparison in Research Brief:** compares selected sources locally — extracting shared tags/references, direct cross-links, unlinked overlaps, line-cited claims (`(L#)`), contrast/caveat tensions, and open questions before you draft a conclusion.
- **Populated Decisions view:** adds a live status summary strip (`open`, `refining`, `accepted`, `superseded`, and overdue review warnings) and expands the default demo vault with six worked decisions across all four columns.
- **Strict offline mode:** opt out of the startup GitHub release check with `--offline`, `CORTEX_OFFLINE=1`, or the toggle in Settings.
- **Release & quality gates:** adds headless Playwright smoke tests across every view and save flow, JS unit tests, static ES module export checks, and repo hygiene checks (blocking committed vault archives) to CI and releases.
- **Landing site & docs:** adds Open Graph / Twitter cards for link previews, elevates Agent-safe MCP on the site and README, removes the previously committed sample vault archive from the repository, and improves escaped-pipe (`\|`) wikilink parsing.
