The “why” layer

Most tools help you collect. Cortex compares your sources and keeps the reasoning.

Select two or more notes to build a Research brief or Refine idea note in plain Markdown. Cortex extracts line-cited claims, shared tags and references, unlinked overlaps, flagged caveats, and open questions — then tracks confidence, review dates, and superseded choices directly from your frontmatter.

Synthesis/ship-the-why-layer.md 
---
type: idea
status: accepted
confidence: 0.8
review_on: 2027-01-15
supersedes: "[[Earlier decision]]"
---
  • Source comparison & citations pull line-numbered claims (L#), shared links, and unlinked overlaps into one brief.
  • Visual confidence meters & review alerts surface stale assumptions when review_on passes.
  • Focus reader & tabbed connections let you read long briefs without losing the vault behind them.

Agent-safe MCP

Let AI clients work in your vault without trusting them blindly.

No built-in LLM or API key is required. When you want Claude Desktop, Cursor, or Zed to read or update notes, cortex mcp enforces strict guardrails over stdio:

  • Deny-by-default access via a per-vault switch (cortex agents ~/Notes --off stops connected clients on the next call).
  • Read-hash preconditions require an exact expect hash from cortex_read_note so edits never clobber concurrent changes.
  • Zero delete tool & strict path checks refuse traversal, symlinks, and .obsidian/ writes; every mutation appends to agent-writes.jsonl.
Configure Claude Desktop & Cursor in one command 
cortex mcp-config --vault ~/Notes --write
cortex mcp ~/Notes
cortex agents ~/Notes --off

Built to outlive any app

Your folder. Plain Markdown. Zero lock-in.

One self-contained Rust binary with a native window on Windows and macOS, Dark & Warm Light studio themes, and an optional MCP server when you want an AI client to work inside your guardrails.

Native & fast

WebView2 on Windows, WKWebView on macOS, loopback server on Linux. Incremental file watching updates your graph in ~400 ms.

Precision Editorial Studio

v2 introduces Dark, Warm Light & System themes, collapsible drag-resizable panels, Focus reading mode, and a unified Ctrl K command palette.

Obsidian & Logseq ready

Open your existing vault in place. Wikilinks, aliases, anchors, tags, and YAML frontmatter work untouched — deleting the app leaves your notes spotless.

Offline-ready & transparent

Zero telemetry and no built-in model. The optional GitHub release check can be toggled off in Vault settings → About or disabled globally with --offline.
